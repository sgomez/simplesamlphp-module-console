## Language

Everything in this repository is in English: code, comments, docs, commit messages, issues and PRs.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`sgomez/simplesamlphp-module-console`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
